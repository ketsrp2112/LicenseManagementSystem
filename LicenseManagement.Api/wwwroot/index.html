Four kinds of application

Pick the one that matches what you need to do with your license.

New License

Register products and apply for a license for the first time.

Renew

Extend an existing license before it expires.

Amendment

Change details or products on a license that is already approved.

Cancel

Withdraw a license you no longer need. The license is marked as cancelled.

Know where your application is

Every application has a clear status, visible to both traders and officers.

  1. Draft

    Trader prepares the application and attaches documents.

  2. Submitted

    Sent to the authority and waiting to be picked up.

  3. Officer Review

    An officer checks the details and documents.

  4. Decision

    The officer approves or rejects the application.

  5. Approved

    A license number is issued and the certificate is available.

If something is missing, the officer sends the application back as Revision Required. The trader fixes it and submits again, and it returns to review.

What you can do in the system

Each account sees only the tools it needs.

Traders / Applicant

Companies applying for or holding a license

  • Create applications and save them as drafts
  • Edit and resubmit when an officer asks for changes
  • Search and follow every application by status
  • View the certificate once the license is approved

Regulatory officers / Staff

Staff who review and decide

  • See a summary of pending work and overdue applications
  • Filter by status, type and date, and sort by waiting time
  • Verify documents, then approve, reject or request changes
  • Export the filtered list to CSV for reports
